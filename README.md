# IPT10 Laboratory Activity #3B: Uploading Files in PHP and Git Branching

This repository demonstrates multi-type file uploading in PHP paired with a structured Git branching workflow (`pdf-file-upload`, `audio-file-upload`, `image-file-upload`, `video-file-upload`, and `main`).

## Feature Branches

- **`main`**: Unified file uploader accepting Text, PDF, Audio (.mp3), Image, and Video (.mp4) files.
- **`pdf-file-upload`**: PDF file upload input and HTML `<embed>` viewer.
- **`audio-file-upload`**: Audio file upload input and HTML5 `<audio controls>` player.
- **`image-file-upload`**: Image file upload input and responsive `<img>` preview.
- **`video-file-upload`**: Video file upload input and HTML5 `<video controls>` player.

## Running Locally

1. Start the PHP server:
   ```bash
   php -S localhost:8000
   ```
2. Open `http://localhost:8000` in your browser.
3. Test uploading files from the `sample-files/` folder!
